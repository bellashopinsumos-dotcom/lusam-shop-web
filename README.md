# LuSam Shop — Editorial Rosé

Tienda pública de moda femenina LuSam Shop. Diseño Editorial Rosé aprobado.

## Estado
Primer despliegue del catálogo visual de demostración. Los productos, precios, existencias y fotografías ilustrativas NO son inventario real; todavía no se aceptan ventas desde esta página.

## Arquitectura prevista
- Este repositorio almacena únicamente el sitio público y el catálogo de productos publicados.
- El administrador y la caja utilizarán un repositorio distinto y privado: `lusam-shop-control`.
- Las modificaciones del inventario se publicarán desde el repositorio privado a la tienda mediante GitHub Actions; esta conexión aún no está activada.
- Nunca añadir tokens de GitHub, contraseñas ni datos de clientes en este repositorio.

Sitio cuando se habilite GitHub Pages: https://bellashopinsumos-dotcom.github.io/lusam-shop-web/

**No utilizar el catálogo de demostración para confirmar pedidos reales.**
